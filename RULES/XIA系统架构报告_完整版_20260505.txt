一、项目概述
================================================================================

XIA 是一个具有情感、驱动力和世界模型的 AI 认知引擎。她的核心理念是：
行为从连续状态空间中自然涌现，而非预设规则。她不是"根据 if-else 决定
该做什么"，而是"所有驱动力叠加后的合力自然导向某个行为"。

核心技术栈:
- 本地 LLM: qwen2.5:3b（Ollama）
- 状态容器: EntityCore（跨轮次持久化）
- 推理管线: entity_zero_iteration（16步同步管线）
- 驱动力模型: 拮抗力场 + 连续质变（V6）
- 行为涌现: V6优先，V5 fallback
- 长期记忆: SQLite episodes + 经验召回
- 常驻进程: daemon（Unix Domain Socket IPC）

核心设计原则:
1. 状态驱动而非时钟驱动
2. 涌现而非预设
3. 纯函数（无内部状态）
4. 失败隔离
5. 零硬编码参数
6. 观测只读

核心职责: 从EntityCore提取raw_drives，经拮抗矩阵计算net_drives，
再计算fragmentation系数alpha，输出完整behavior_vector。

驱动力维度（状态层）:
  loneliness, fatigue, info_gap, unresolved, somatic_tone_p, danger

拮抗矩阵（DEFAULT_ANTAGONISM_MATRIX）:
  - fatigue强抑制 loneliness(0.6)/info_gap(0.55)/unresolved(0.5)
  - danger强抑制 info_gap(0.4)/unresolved(0.2)
  - somatic_tone_p抑制 danger(0.35)/fatigue(0.20)
  - loneliness抑制 info_gap(0.20)

连续质变（fragmentation）:
  alpha[dst] = clamp(Σ sigmoid(k*raw_src*weight)*raw_src / max(1,Σraw_src), 0, 1)
  behavior_vector[dst_intensity] = net * (1 - alpha²)
  behavior_vector[dst_fragmentation] = net * alpha²
  （加权平均避免alpha越界，避免alpha=1时intensity塌陷为0）

核心职责: 从历史经验中归纳rule effect，将偏置加到behavior_vector上。
无任何人工预设effect值。

Rule Effect归纳流程:
  历史snapshots → pre/post差分 → EMA更新rule.effect
  当前状态 + rule.context_mean → 余弦相似度 → alpha偏置
  偏置叠加 → 新的behavior_vector

关键数据结构 BehaviorRule:
  - action_type: 动作类型
  - effect: {dim: delta}，从snapshots归纳
  - strength: 置信度 [0,1]
  - count: 触发次数
  - context_mean: 学习时的平均状态
  - last_seen_tick: 最近触发tick

核心函数:
  - update_rules_from_snapshot(entity_core, snap, tick): 从snapshot归纳/更新rule
  - _context_similarity(current_state, rule_context): 余弦相似度
  - apply_rule_bias(behavior_vector, entity_core): 应用偏置
  - get_rules() / save_rules(): rule存储读写

偏置公式:
  alpha = max_alpha * strength * context_sim
  bias = alpha * reduction * current_drive_level
  (reduction = |post-pre|，正效果→intensity↑，负效果→intensity↓)

偏置上限: MAX_BIAS = 0.15（防止极端rule破坏行为）

核心职责: 统一算力账本：energy = 总算力 - 所有当前负载。
energy是瞬时状态，不是累积量。

算力账本模型:
  energy = 1.0 - sum(social + cognitive + info + meta +
                     emotional + stress + fatigue_delay +
                     frontload + idle)

负载来源:
  - social: 社交信息缺失评估（有输入则归零）
  - cognitive: 认知负荷（预测误差驱动）
  - info: 信息缺口评估
  - meta: 元信息处理（极低，不可消除）
  - emotional: 负面情绪额外线程
  - stress: 高优先级中断通道
  - fatigue_delay: 处理延迟（队列长则延迟大）
  - frontload: 前台对话占用
  - idle: 基础运转开销

关键子模块:
  - InfoQueue: 五种后台信息队列建模
  - compute_load: 算力占用计算、stress生命周期、rest触发
  - compute_connection.py: connection_depth + loneliness_target
  - compute_coherence.py: coherence计算
  - world_model_update/resolve.py: stress生命周期完整闭环

核心机制:
  - stress = 未处理的意外信号数量（pending_surprises），不走半衰期
  - rest触发: 队列积累速率 > 消化速率 × 1.2（独立于energy）
  - pending_surprises: 预测误差>0.3时产生新surprise
  - relief_debt: 舒适负债演化（独立于算力账本）
  - 时间注入维度的恢复阻尼（×0.5）

loneliness更新规则（v4.0严格因果）:
  - 有真实用户输入 → 目标=0（直接跳转）
  - 无社交输入 → 目标向1.0累积（rise_rate=0.01/tick）
  - 禁止无因果来源的自然衰减

核心职责: 联合计算connection_depth（四层级：v3.0+v3.5a+b+c），
以及loneliness_target计算。

四层级架构:
  v3.0  : connection_depth = 加权公式（三因子：prediction/somatic/tension）
  v3.5a : 权重从参数快照读取（实例差异化）
  v3.5b : 经验偏移从memory_context检索（正负双向余弦相似度）
  v3.5c : coherence短期调制（含负向阻尼）

connection_depth公式:
  connection_depth = (
      w_prediction * (1 - prediction_error) +
      w_somatic * somatic_factor +
      w_tension * (1 - tension_level)
  ) / (w_pred + w_som + w_tension)

somatic_factor查表: delta>0.1→1.0, delta∈[-0.1,0.1]→0.5, delta<-0.1→-0.5

================================================================================
六、关键设计亮点
================================================================================

1. 拮抗力场（drive_vector_field.py）
   驱动力不是argmax选择，而是六维向量完整保留。拮抗矩阵让各力相互压制，
   fragmentation系数让行为有质地（断断续续 vs 清晰连贯），而非硬切换。

2. 内生rule effect（behavior_vector.py）
   从历史snapshots归纳action效果，EMA更新，完全无需人工预设。
   context_similarity确保只有相似情境才应用偏置。

3. 算力账本（update_engine.py）
   energy=总算力-负载，负载来源清晰分层。rest时队列被消化→负载降低→
   energy回升，物理意义明确。

4. connection_depth四层（compute_connection.py）
   v3.0基础公式 + v3.5a差异化权重 + v3.5b经验偏移 + v3.5c coherence调制。

5. 观测只读（behavior_trace.py）
   所有trace数据不参与决策，仅供分析和调试。
